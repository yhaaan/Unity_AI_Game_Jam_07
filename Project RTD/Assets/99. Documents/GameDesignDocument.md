# Project RTD 게임 기획서

> 상태: 초기 기획 정리  
> 이 문서는 현재까지 확정된 내용만 기록하며, 세부 동작과 수치는 추후 갱신한다.

## 1. 게임 개요

- 장르: 2D 사이드 뷰 플랫포머 퍼즐
- 목표 플랫폼: Windows PC
- 목표 플레이 시간: 첫 플레이 기준 20~30분
- 구성: 짧은 튜토리얼 1개와 정규 스테이지 3개
- 클리어 목표: 각 스테이지의 출구 도달
- 진행 방식: 튜토리얼부터 정규 스테이지 3까지 순차 진행
- 저장 기능: 현재 범위에서는 제외
- 클리어 평가: 시간, 실패 횟수, 등급 없이 클리어 여부만 판정

## 2. 핵심 콘셉트

스테이지에 입장할 때 동물의 머리, 몸통(팔), 다리를 무작위로 조립한 캐릭터가 소환된다. 각 파츠의 장점과 약점, 스탯을 이용해 퍼즐을 해결하고 출구까지 도달한다.

같은 퍼즐에도 여러 해결 경로를 제공한다. 모든 조합이 사용할 수 있는 어렵거나 긴 공용 해법을 두고, 적합한 파츠를 가진 조합은 더 쉽거나 빠른 특수 경로를 사용할 수 있다.

## 3. 기본 플레이 흐름

1. 스테이지 입장 시 머리, 몸통, 다리를 각각 독립적으로 무작위 추첨한다.
2. 조립된 캐릭터의 파츠별 장점과 약점, 최종 스탯을 모두 공개한다.
3. 플레이어는 현재 조합으로 도전하거나 제한된 재소환 기회를 사용한다.
4. 선택한 조합은 스테이지가 끝날 때까지 유지된다.
5. 실패하면 체크포인트 없이 스테이지 시작 지점으로 돌아간다.
6. 실패 후에도 기존 조합을 유지하며, 시작 지점에서 원할 때만 재소환 기회를 소비한다.
7. 출구에 도달하면 다음 스테이지가 열린다.

재소환 가능 횟수와 세부 규칙은 추후 결정한다.

## 4. 캐릭터 조립 규칙

- 조립 슬롯은 머리, 몸통(팔), 다리의 세 부위다.
- 각 부위는 동물 5종 중 하나를 같은 확률로 독립 추첨한다.
- 완전한 단일 동물과 여러 동물이 섞인 조합이 모두 나올 수 있다.
- 같은 동물 파츠를 여러 개 장착해도 별도의 세트 효과는 없다.
- 표에서 `-`로 표시된 파츠도 추첨 대상이며, 특수효과가 없는 중립 파츠로 취급한다.
- 장식은 별도 슬롯이 아니라 관련 머리 또는 몸통 파츠의 외형에 포함한다.
- 적과 환경 객체가 인식하는 동물의 정체성은 머리 파츠가 결정한다.

### 장식 연결

- 닭벼슬: 닭 머리
- 원숭이 꼬리: 원숭이 몸통
- 갈기: 사자 머리
- 캥거루 꼬리: 캥거루 몸통
- 오리 부리: 오리 머리

## 5. 스탯 규칙

기본 스탯은 다음 네 가지다.

- 이동속도
- 점프력
- 무게
- 체력

모든 스탯은 내부적으로 1~5단계이며, 플레이어에게는 다음과 같이 표시할 수 있다.

| 단계 | 표시 |
| ---: | --- |
| 1 | 매우 낮음 |
| 2 | 낮음 |
| 3 | 보통 |
| 4 | 높음 |
| 5 | 매우 높음 |

### 계산 방식

- 모든 캐릭터는 각 스탯 3단계에서 시작한다.
- 각 파츠의 보정을 합산한 뒤 최종 결과를 1~5 범위로 제한한다.
- 현재 표기 기준으로 `+`는 +1, `++`는 +2, 낮음 또는 약화는 -1로 해석한다.
- 최종 무게가 4 이상이면 최종 이동속도가 1단계 감소한다.
- 무게로 인한 이동속도는 최소 1단계를 유지한다.
- 무게는 점프력과 낙하 속도에는 영향을 주지 않는다.
- 체력은 현재 1~5단계 변수만 정의하며, 피해와 회복 방식은 추후 결정한다.

## 6. 동물 파츠

| 동물 | 머리 | 몸통(팔) | 다리 |
| --- | --- | --- | --- |
| 닭 | 무게 -1, 이동 중 주기적으로 좌우 한쪽으로 쏠림 | 활강 가능, 체력 -1 | 무게 -1, 이동속도 +1, 점프력 +1, 키가 작음 |
| 원숭이 | 바나나를 보면 광분 | 벽타기 가능, 체력 +1 | 특수효과 없음 |
| 사자 | 포식자에게 안전하게 통과 가능, 무게 +1 | 체력 +2 | 이동속도 +1 |
| 캥거루 | 사냥꾼에게 불리 | 체력 +2 | 점프력 +1 |
| 오리 | 사냥꾼에게 불리 | 물에 뜰 수 있음 | 점프력 -1 |

### 현재 확정된 세부 해석

- 닭 머리의 불안정함은 이동 중 주기적인 좌우 쏠림으로 표현한다.
- 닭 다리는 전체 캐릭터의 콜라이더를 낮춘다. 낮은 통로를 지날 수 있지만 높은 접촉 지점에는 닿기 어려워진다.
- 오리 몸통이 아닌 캐릭터에게 물은 실패 구역이다. 오리 몸통은 물에 떠서 수면 경로를 이용할 수 있다.
- 활강, 벽타기 등 파츠 능력은 별도의 능력 버튼 없이 이동, 점프, 상황 판정에 통합한다.

## 7. 퍼즐 및 레벨 설계 원칙

- 각 정규 스테이지는 여러 퍼즐 구간이 이어지는 짧은 횡스크롤 구조다.
- 퍼즐의 해법 발견을 중심 난이도로 삼고, 이동과 점프 판정은 관대하게 만든다.
- 모든 조합이 사용할 수 있는 공용 해법을 반드시 제공한다.
- 파츠 능력은 공용 해법보다 쉽거나 빠른 대체 경로를 제공한다.
- 모든 캐릭터는 별도 버튼 없이 물체를 몸으로 밀고 발판을 밟을 수 있다.
- 상자는 필요한 최소 무게 단계를 가지며, 무게가 부족한 조합은 우회 해법을 사용한다.
- 발판, 바닥, 승강기 등의 환경 오브젝트는 무게 단계 임계값으로 반응한다.
- 가벼운 조합과 무거운 조합이 서로 다른 상황에서 장점을 갖도록 설계한다.

### 스테이지별 기믹 전개

- 스테이지 1: 기본 이동과 무게 기믹
- 스테이지 2: 물과 수직 이동 기믹
- 스테이지 3: 적의 머리 인식과 기존 기믹의 종합

스테이지별 정확한 퍼즐 구간 수는 추후 결정한다.

## 8. 최소 화면 구성

- 타이틀 화면
- 조작 안내
- 조립 결과와 파츠·스탯 확인 화면
- 일시정지 화면: 계속, 스테이지 재시작, 종료
- 스테이지 클리어 화면
- 엔딩 화면

- 세계관과 무작위 조립의 서사적 이유
- 아트 스타일

- 재소환 가능 횟수와 비용
- 체력의 피해, 회복, 실패 처리
- 활강과 벽타기의 세부 입력 및 판정
- 원숭이 머리의 바나나 광분 동작
- 포식자와 사냥꾼의 감지, 추격, 공격 방식
- 스테이지별 퍼즐 구간 수와 실제 레이아웃
- 각 스탯 단계가 실제 이동·점프 수치로 변환되는 값
- 세부 실패 조건
- 사운드와 연출
